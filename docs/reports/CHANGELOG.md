# 報告書作成機能 変更履歴

## [2024-12-XX] - リアルタイムプレビュー機能の追加

### 追加
- リアルタイムプレビューコンポーネント（`report-preview.tsx`）を追加
- フィールド入力中と画像アップロード中にサイドパネルでリアルタイムプレビューを表示
- アップロード済み画像の取得と表示機能
- 画像削除時のプレビュー更新機能

### 改善
- `ReportForm`コンポーネントにサイドパネルレイアウトを追加
- デスクトップ（lg以上）ではサイドパネルで常時表示、モバイルでは非表示のレスポンシブ対応
- 画像アップロード成功時に自動的にプレビューを更新

### 技術的詳細
- `watch()`を使用してフォームの値をリアルタイムで監視
- 画像アップロードAPIから取得した画像情報をstateで管理
- 型安全性を確保するための型アサーションを追加
